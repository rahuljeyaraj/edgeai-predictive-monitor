⚙️ Motor Driver

⚠️ Web Serial not available

This dashboard needs the Web Serial API. Open this file in desktop Chrome or Edge (not Firefox/Safari), served from file:// or localhost. Then click Connect and pick the Arduino Uno's port.

⚠️ Serving without the rig host

This page is open without motor_driver.py behind it, so it can only drive motors. Installing or removing a motor, the protection status, and trip alerts all need the rig host — start it with ./start_motor_driver.sh --port /dev/ttyACM0.
